# Fun check

The prototype exists to answer **is it fun?** This skill turns a playtest into a logged verdict.

## Steps

1. Ask Theo the five questions from `docs/design/GDD.md` → *Fun tests*, one at a time. Record each answer as **yes / no / unsure** plus his own words.
2. Ask for the one moment he'd tell a friend about. No moment is a valid answer and a strong signal.
3. Write `docs/playtests/YYYY-MM-DD-P<n>.md` using `docs/playtests/TEMPLATE.md`.
4. Give the verdict:
   - **Go**: 3+ clear yes.
   - **Tune**: questions 2 and 3 are no. The emergence is flat; propose one change to chaos, quirks, or needs, not new content.
   - **Rethink**: 2 or fewer yes after P6. Summarise the evidence plainly for a keep-or-kill decision.

## Done when

The playtest file exists, every question has an answer, and the verdict names one next action.
