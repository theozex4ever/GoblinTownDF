# Tickets

One Markdown file per ticket, named `P<milestone>-<nn>-<slug>.md` (for example `P1-01-tile-grid.md`). Created with the `to-tickets` skill.

Each ticket holds:

- **Milestone:** P1–P6
- **GDD section:** the section it implements
- **Blocked by:** other ticket files, or none
- **Done when:** one checkable condition, such as "test X passes and the game runs with zero console errors"
